# Sage Graphite token snapshot

This local Swift package contains only the colour-token portion of Sage Graphite used by the
Sage Active prototype. It intentionally excludes Graphite UI components, image-loading
dependencies, and build-tool plugins.

The snapshot was copied from the authorised `sage_graphite_mobile_ios` `develop` download on
10 August 2026. Replace this package or update `SageActiveTheme` when the future Sage DS token
library becomes available.
